## 📋 What's Inside

This interactive HTML guide covers **6 complete sections** sourced exclusively from [knowledge.apollo.io](https://knowledge.apollo.io) and [docs.apollo.io](https://docs.apollo.io):

| Step | Section | Key Topics |
|------|---------|------------|
| 01 | 🎯 **Build List** | ICP definition · People filters · Enrichment · Credit management |
| 02 | 📧 **Create Sequence** | Omnichannel cadence · Rulesets · Verified contacts · A/B testing |
| 03 | ⚡ **Build Workflow** | Triggers · Enrollment filters · Multi-split branches · Re-enrollment |
| 04 | 🌐 **Website Visitors** | Tracking snippet · High-intent pages · Automated visitor workflows |
| 05 | 📝 **Forms** | Form enrichment · Auto-fill · Inbound Routers · Lead routing |
| 06 | 📊 **Monitor & Iterate** | Performance benchmarks · Domain health · Iteration loop |

---

## ✨ Features

- **Interactive tabs** — navigate between all 6 sections
- **Expandable cards** — click each best practice to reveal full details
- **Progress tracker** — tracks which sections you've reviewed
- **Interactive checklists** — mark setup tasks as complete
- **Direct links** — every card links to the official Apollo.io documentation
- **Fully standalone** — no internet connection required (except Google Fonts)
- **Mobile responsive** — works on phones and tablets
